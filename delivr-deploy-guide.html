Delivr Production
Setup Guide

Από το ZIP στο production URL σε λιγότερο από 30 λεπτά. Βήμα-βήμα για κάθε service.

Αρχιτεκτονική

Το Delivr είναι ένα JAMstack application — το frontend είναι static HTML/JS που τρέχει στον browser του χρήστη, και επικοινωνεί με το Supabase backend και τα Stripe APIs.

💡
Zero server maintenance

Δεν χρειάζεσαι δικό σου server για να τρέξεις το Delivr. Vercel (frontend) + Supabase (backend) + Stripe (payments) = πλήρης production stack σε δωρεάν tiers.

ComponentServiceΤιμολόγηση
FrontendVercelΔωρεάν (Hobby) / $20/μήνα (Pro)
Database + AuthSupabaseΔωρεάν / $25/μήνα (Pro)
Edge FunctionsSupabaseIncluded (500K calls/μήνα)
PaymentsStripe2.9% + €0.30 ανά συναλλαγή
SMSTwilio~€0.05 ανά SMS
EmailResendΔωρεάν (3K/μήνα) / $20 (50K)

Local Setup (5 λεπτά)

1 Αποσυμπίεση & εγκατάσταση

bash
# Αποσυμπίεση
unzip delivr-final.zip
cd delivr

# Εγκατάσταση dependencies (~2 λεπτά)
npm install

# Δημιούργησε το env file
cp .env.example .env.local
nano .env.local  # ή οποιοδήποτε editor

2 Συμπλήρωσε τα env variables

.env.local
# Αυτά είναι τα ΜΟΝΟ απαραίτητα για local dev:

VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI...

# Stripe (χρησιμοποίησε test keys αρχικά)
VITE_STRIPE_PUBLISHABLE_KEY=pk_test_...

# Αυτά προσθέτεις αργότερα:
# VITE_GOOGLE_MAPS_KEY=...
# VITE_VAPID_PUBLIC_KEY=...

3 Εκκίνηση dev server

bash
npm run dev

# Output:
  VITE v5.0.8  ready in 312 ms
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.1.x:5173/

# Τέσσερα URLs:
# /home      → Customer App
# /merchant  → Merchant POS
# /driver    → Driver App
# /admin     → Admin Panel

Supabase Setup

Δημιούργησε νέο project

  1. Πήγαινε στο supabase.com → New project
  2. Όνομα: delivr-production, επέλεξε region EU (Frankfurt)
  3. Βάλε ένα strong database password — αποθήκευσέ το!
  4. Περίμενε ~2 λεπτά για initialization

Τρέξε το database schema

⚠️
Σειρά εκτέλεσης

Πρώτα τρέξε το supabase-schema.sql, μετά το 002_driver_sessions_notifications.sql. Η σειρά μετράει.

supabase SQL Editor
-- Βήμα 1: Supabase Dashboard → SQL Editor → New Query
-- Paste όλο το περιεχόμενο του: supabase-schema.sql
-- Πάτησε: Run (Ctrl+Enter)

-- Βήμα 2: New Query ξανά
-- Paste: supabase/migrations/002_driver_sessions_notifications.sql
-- Run

-- Βήμα 3: Ενεργοποίησε pg_net extension
-- Database → Extensions → αναζήτηση "pg_net" → Enable

-- Βήμα 4: Βάλε τα app config values
ALTER DATABASE postgres SET app.supabase_url = 'https://xxx.supabase.co';
ALTER DATABASE postgres SET app.service_role_key = 'eyJ...';

Ενεργοποίησε Google Auth (προαιρετικό)

Supabase Dashboard
# Authentication → Providers → Google → Enable
# Χρειάζεσαι Google OAuth credentials:
# console.cloud.google.com → APIs → Credentials → OAuth 2.0
# Authorized redirect URI:
https://YOUR_PROJECT.supabase.co/auth/v1/callback

Πάρε τα API keys

bash
# Supabase Dashboard → Project Settings → API
# Copy τα παρακάτω στο .env.local:

VITE_SUPABASE_URL     = Project URL (https://xxx.supabase.co)
VITE_SUPABASE_ANON_KEY = anon / public key (eyJ...)

# Αυτό ΔΕΝ το βάζεις στο .env.local (κινδυνεύει να εκτεθεί)
# Το βάζεις ΜΟΝΟ στο Supabase Edge Function Secrets:
SUPABASE_SERVICE_ROLE_KEY = service_role key (eyJ...)

Stripe Setup

API Keys

bash
# dashboard.stripe.com → Developers → API Keys

# Frontend (.env.local):
VITE_STRIPE_PUBLISHABLE_KEY=pk_test_...  # test
VITE_STRIPE_PUBLISHABLE_KEY=pk_live_...  # production

# Edge Functions (Supabase Dashboard → Settings → Secrets):
STRIPE_SECRET_KEY=sk_test_...  # ή sk_live_ για production

Webhook Setup

bash
# Stripe Dashboard → Developers → Webhooks → Add endpoint

# Endpoint URL (η Supabase Edge Function):
https://YOUR_PROJECT_REF.supabase.co/functions/v1/order-status-webhook

# Events to listen:
payment_intent.succeeded
payment_intent.payment_failed
charge.refunded
customer.updated

# Copy το Signing secret:
STRIPE_WEBHOOK_SECRET=whsec_...
# → βάλε το στο Supabase Secrets

Edge Functions Deploy

bash
# Εγκατάσταση Supabase CLI
npm install -g supabase

# Login
supabase login
# → Ανοίγει browser για authentication

# Βρες το project ref στο Supabase Dashboard → Settings → General
supabase link --project-ref YOUR_PROJECT_REF

# Deploy όλες τις functions ταυτόχρονα
supabase functions deploy

# Ή μία-μία:
supabase functions deploy create-payment-intent
supabase functions deploy confirm-order
supabase functions deploy send-notification
supabase functions deploy order-status-webhook
supabase functions deploy assign-driver

# Πρόσθεσε τα secrets:
supabase secrets set STRIPE_SECRET_KEY=sk_live_...
supabase secrets set STRIPE_WEBHOOK_SECRET=whsec_...
supabase secrets set TWILIO_ACCOUNT_SID=AC...
supabase secrets set RESEND_API_KEY=re_...
supabase secrets set APP_URL=https://yourdomain.gr

Deploy στο Vercel

Option A: Vercel CLI (γρηγορότερο)

bash
# Εγκατάσταση Vercel CLI
npm install -g vercel

# Build
npm run build

# Deploy (θα σε ρωτήσει να κάνεις login)
vercel --prod

# Output:
✓  Production: https://delivr-xyz.vercel.app [3s]

Option B: GitHub + Vercel (auto-deploy)

bash
# 1. Δημιούργησε GitHub repo
git init
git add .
git commit -m "initial commit"
git remote add origin https://github.com/YOU/delivr
git push -u origin main

# 2. vercel.com/new → Import Git Repository
# 3. Framework: Vite (auto-detected)
# 4. Πρόσθεσε env vars (βλέπε παρακάτω)
# 5. Deploy!

# Από εδώ και μετά: κάθε git push → auto-deploy ✓

Env Variables στο Vercel

🔐
Σημαντικό

Μην βάλεις ποτέ STRIPE_SECRET_KEY ή SUPABASE_SERVICE_ROLE_KEY στο Vercel — αυτά ανήκουν μόνο στα Supabase Edge Function Secrets.

Vercel Dashboard → Settings → Environment Variables
# Βάλε αυτά (και ΜΟΝΟ αυτά) στο Vercel:
VITE_SUPABASE_URL           = https://xxx.supabase.co
VITE_SUPABASE_ANON_KEY      = eyJ...  (public, OK)
VITE_STRIPE_PUBLISHABLE_KEY = pk_live_...  (public, OK)
VITE_GOOGLE_MAPS_KEY        = AIza...
VITE_APP_URL                = https://yourdomain.gr

Deploy στο Netlify

bash
npm install -g netlify-cli
npm run build
netlify deploy --prod --dir=dist

# Ή μέσω netlify.toml (στο root του project):
netlify.toml
[build]
  command   = "npm run build"
  publish   = "dist"

[[redirects]]
  from   = "/*"
  to     = "/index.html"
  status = 200

Docker / VPS

Dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
bash
# Build & run
docker build -t delivr .
docker run -p 80:80 --env-file .env.production delivr

# Ή με docker-compose:
docker-compose up -d

# Recommended VPS: Hetzner CX21 (2vCPU, 4GB RAM, €4.15/μήνα)
# Με Nginx + Let's Encrypt SSL για free HTTPS

Custom Domain

DNS Records (στον provider σου)
# Για Vercel:
CNAME  www    → cname.vercel-dns.com
A      @      → 76.76.21.21

# Για Netlify:
CNAME  www    → YOUR_SITE.netlify.app

# SSL: Αυτόματο από Vercel/Netlify (Let's Encrypt)

# Authentication → URL Configuration
# Site URL: https://www.yourdomain.gr
