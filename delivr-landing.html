Deploy Guide

Στον αέρα
σε <30 λεπτά.

Από το ZIP στο production με 6 βήματα. Δεν χρειάζεσαι server — όλα στο cloud.

1
Κατέβασε & εγκατέστησε
Node.js 18+ απαιτείται
# Αποσυμπίεση του project unzip delivr-final.zip && cd delivr # Εγκατάσταση dependencies npm install # Δημιουργία env file cp .env.example .env.local
2
Supabase Setup
supabase.com → New Project
# 1. Πήγαινε στο supabase.com # 2. New Project → όνομα "delivr" # 3. SQL Editor → New Query # Paste: supabase-schema.sql # Paste: migrations/002_*.sql # 4. Settings → API → copy keys VITE_SUPABASE_URL=https://xxx.supabase.co VITE_SUPABASE_ANON_KEY=eyJhbGc...
3
Stripe Setup
dashboard.stripe.com
# Stripe Dashboard → Developers → API Keys VITE_STRIPE_PUBLISHABLE_KEY=pk_test_... # Edge Function Secrets (Supabase Dashboard) # Settings → Secrets → Add new secret STRIPE_SECRET_KEY=sk_test_... # Webhooks → Add endpoint # URL: https://xxx.supabase.co/ # functions/v1/order-status-webhook
4
Deploy Edge Functions
Supabase CLI
# Εγκατάσταση Supabase CLI npm install -g supabase # Login supabase login # Link με το project σου supabase link --project-ref YOUR_REF # Deploy όλες τις functions supabase functions deploy
5
Build & Deploy στο Vercel
Δωρεάν για hobby projects
# Build για production npm run build # Option A: Vercel CLI (recommended) npm i -g vercel vercel --prod # Option B: GitHub → Vercel # Push στο GitHub, connect repo # στο vercel.com/new # Προσθήκη env vars στο # Vercel Dashboard → Settings → Env
6
Custom Domain (προαιρετικό)
delivr.yourdomain.gr
# Vercel Dashboard → Domains → Add # Πρόσθεσε CNAME στον DNS provider σου: CNAME delivr → cname.vercel-dns.com # SSL certificate: αυτόματο από Vercel # Supabase Auth → URL Configuration # Site URL: https://delivr.yourdomain.gr # Redirect URLs: https://delivr.yourdomain.gr/*
